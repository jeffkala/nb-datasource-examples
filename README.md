# Demonstrates Many DataSources in One Repository

Nautobot supports syncing in many different data objects from Git repositories, this repo intends to give simple examples and folder structures that worth with core and open source apps.

### Main Branch

The main branch serves to put all the examples into after they've been written. There is no assumption that all of these work, but they should give you a starting point.

If an example should get into the `main` branch a PR should be opened.

### empty-branch Branch

This has the the folder structure with `.gitkeep` files in it. This is an easy branch to start from, whether you are just testing a few things or want a simple starting structure.

This is most likely the best branch to checkout and branch off of when developing something from scratch.
